# Security

Report vulnerabilities in tonia Pass, the official SDKs, or this organization
to **security@tonia.ca**. Do not open a public GitHub issue for a security
report.

Include the affected repository or package, versions, and steps to reproduce
when you can. We will acknowledge receipt.

Privacy requests: [privacy@tonia.ca](mailto:privacy@tonia.ca).
Product support: [support@tonia.ca](mailto:support@tonia.ca).
